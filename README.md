A Python program that draws, entirely in code, the open passport spread of the Republic of Vessia — a small alpine republic that does not exist. Data page with portrait, bilingual Vessian labels and machine-readable zone; facing page with the border stamps of a plausible 2023 journey to Kharovia and Ostrem, and one telling detail: a High Pass winter-crossing permit. Every date agrees with every other.

## Run it

```sh
python3 main.py
```
